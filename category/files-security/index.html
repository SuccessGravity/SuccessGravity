🔐 Files, E-signature & Security Tools

Office suites, cloud storage, e-signature and password managers — the back-office basics, with entry prices checked at the source.

Last updated: October 2026 · 33 tools · Prices checked at the source

These are the tools nobody talks about but every business needs: somewhere to keep files, a way to get contracts signed, and a password manager so shared logins aren't living in a spreadsheet.

Office suites often bundle several of these (storage, email, sometimes e-signature), so check what your suite already covers before paying for a standalone tool.

What to look for

  • Storage per user and file-sharing controls
  • E-signature: number of envelopes or documents included per month
  • Password managers: shared vaults and admin controls for teams
  • Two-factor authentication and audit logs
